# CBTI 摄影人格测试

> Camera-Based Type Indicator —— 24 道题，12 种摄影人格，5 分钟测出你是哪种"拍照人"。

一个极简风格的高保真网页原型，借用 MBTI 的形式帮你定位自己的摄影偏好与人格类型。结果以"你最像哪个相机品牌"的方式呈现——从富士的氛围派、徕卡的观察者，到大疆的上帝视角、徐州老味菜的混沌拼盘。

---

## ✨ 特性

- **24 道情境题**：不考专业知识，只问你怎么看、怎么拍、怎么感受
- **12 种人格类型**：FUJI / CANON / SONY / NIKON / LEICA / HASSELBLAD / OLYMPUS / RICOH / APPLE / ANDROID / DJI / XZLWC（徐州老味菜）
- **12 维人格向量**：情绪表达 E、技术掌控 T、社交取向 S、机动轻便 M、仪式审美 A、稳定保守 R、人像 P、街头 ST、风景 L、野生 W、细节 D、视频 C
- **余弦相似度匹配**：而不是简单分桶，结果更细腻
- **结果页相似度排名**：显示 Top 3 最接近的人格类型 + 完整维度分布
- **古典金色相框**：每个人格配对应风格摄影师 + 风格化 SVG 画面
- **极简低饱和视觉**：奶油白底 + 暖琥珀点缀 + 圆角卡片 + Noto Serif SC + DM Mono

## 🧮 算法说明

每道题的每个选项会给若干个维度加分（例如选 A 给 `M:2, ST:1`）。答完 24 题后：

1. 累加得到用户的 12 维向量
2. 与 12 个原型人格向量逐一计算**余弦相似度**
3. 主维度（前 6 维：人格倾向）权重 0.7，副维度（后 6 维：拍摄题材）权重 0.3
4. 加权后取最高分作为主结果，前三作为相似度排名

每个人格的原型向量（`PROTOS`）都基于品牌使用者画像设计，例如：

- LEICA：高 A（审美）、高 ST（街头）、低 T（不爱炫技）
- SONY：高 T（技术）、高 C（视频）
- DJI：高 T（航拍科技）、高 L（风景大场面）

## ⚖️ 关于内容版权

> 当前版本中，相框里展示的"摄影师作品"**并非真实照片**，而是用 SVG 代码绘制的风格化致敬画面。这是为了规避版权问题做的临时方案。

每种人格关联了一位真实的网红 / 著名摄影师作为风格代表（仅文字署名），但**未使用其任何实际作品**。如需进一步公开发布或商用，需要：

- 联系摄影师授权使用作品
- 或改用方向 4（见下方 Roadmap）

## 🗺️ Roadmap

### v2 计划：用户上传作品 → "你 vs 你的代表风格"对比图

不再展示他人作品，改为：

- 测完后引导用户**上传自己最满意的一张照片**
- 古典相框里放的是**用户自己的作品**
- 旁边附一行小字："你的作品 · 风格更接近 [摄影师名字]"
- 结果页可一键生成分享卡片，传播性更强、版权零风险

这样把"测试结果"从单向告知变成"自我表达 + 风格定位"的工具，分享场景天然契合小红书 / 朋友圈。
